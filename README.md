### Token和字数怎么换算

一个常用的参考值：1000个汉字约等于1500～2000个Token，一段500字的内容大概是750～1000个Token。有了这个换算，成本就能提前估出来。

举两个例子。用Qwen-Plus读一本50万字的书，输入约75万～100万Token，按0.8元/百万算，输入成本0.6～0.8元；让它生成1万字的总结，输出约1.5万～2万Token，按2元/百万算只要3～4分钱。单价看着是零头，量大之后差距才会显现，这也是为什么后面的省钱方式值得认真看。

另外，部分模型有阶梯计费：单次请求的输入Token量越大，单价越低。处理整本书、整批文档时，实际成本可能比按标价直接相乘更低。
